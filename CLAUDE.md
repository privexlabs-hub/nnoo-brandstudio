# Nnọọ Brand Studio (standalone Vite + React app)

Rebuilt from the Claude Design export in `docs/Brand Design System Implementation Update/` (the reference source; never edit it). The export's `*.dc.html` pages used a custom runtime: `{{ hole }}` = value from `renderVals()`, `<sc-for list as>` = map, `<sc-if value>` = conditional, `<dc-import name="Nnoo Page" view>` = `<Page view>`, `style-hover`/`style-active`/`style-focus` attrs = CSS pseudo states, `hint-*` attrs = ignore.

## Layout
- `src/lib/` — ported data + pure logic (tokens, templates, render, export, store, voice, app). Keep edits minimal; asset paths are absolute `/assets/brand/...`.
- `src/styles/tokens.css` (brand tokens, from `_ds/.../colors_and_type.css`), `dark.css` (GENERATED by `npm run gen:dark` from `tokens.js`), `base.css` (shared UI primitives).
- `src/components/` — shared: `AppHeader` (prop `active`: studio|system|playbook|voice|assets|templates|editor), `ThemeSwitch`, `ToastHost` (mounted once in App), `Icon` (`<Icon name="copy" />`, or pass a raw Lucide path as `name`), `Modal` (dialog ≥640px, bottom sheet below), `Page` (renders a `pageView()` view-model; keep its data-* attrs), `PageThumb` (`doc`, `index`, `maxW`, `maxH`), `useHash` hook.
- `src/pages/<Page>.jsx` — one route each. Page-specific sub-components go in `src/pages/<page-name>/`.

## Routes (old file → new path)
`Brand Studio.dc.html` → `/` · `Design System.dc.html` → `/design-system` (`#ds-<id>`) · `Brand Playbook.dc.html` → `/playbook` · `Brand Voice.dc.html` → `/voice` (`#sec-<id>`) · `Asset Library.dc.html` → `/assets` · `Template Library.dc.html` → `/templates` (`#cat=<id>`) · `Editor.dc.html` → `/editor` (`#doc=<id>&page=n` or `#template=<id>&format=&title=&subtitle=`) · `zz Gallery Test.dc.html` → `/gallery-test` (unlisted). Use react-router `<Link>` for internal links.

## Conventions
- UI colours: semantic CSS vars only (`var(--bg)`, `--fg`, `--brand`…) so light/dark work. Brand artwork (logos, swatches, page renders) uses raw tokens/hex.
- Shared classes in `base.css`: `.wrap`, `.grid-auto`/`.grid-fit` (set `--min`, `--gap`), `.stack`, `.row`, `.scroll-x` (wrap every wide table), `.card`, `.card-raised`, `.btn` + `.btn-primary|soft|outline|ghost|inverse|danger`, `.btn-sm`, `.icon-btn(.sm)`, `.chip` (mono copy chip), `.pill` (+`aria-pressed`), `.pill-row`, `.badge`, `.field`/`.input`/`.select`/`.textarea`, `.table`, `.eyebrow-ui`, `.h-page`, `.h-sec`, `.h-card`, `.lead`, `.muted`, `.subtle`, `.small`, `.mono-ui`, `.sr-only`.
- Responsive: CSS media queries (breakpoints 640 / 1024 / 1440; header 1080). No horizontal page scroll at 320px. Touch targets ≥44px on `(pointer: coarse)`. Use `100dvh` and `env(safe-area-inset-*)`.
- Copy: `copyText(str)` from `lib/app.js` (toasts automatically; `.catch(() => toast('Copy failed', 'err'))`). Downloads: `download(blobOrUrl, filename)`. Toasts: `toast(msg, 'ok'|'err')`.
- Brand voice: sentence case, keep Igbo diacritics (ọ ị ụ ń), no emoji, no ALL CAPS except eyebrows.
