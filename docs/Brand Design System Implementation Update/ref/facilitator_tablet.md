# Facilitator tablet — Nnọọ

Field-recording UI for community volunteers sitting with elders. Landscape tablet layout with 320px left rail (session + checklist + guidance) and a main content area that flows through three phases: **setup → recording → review**.

Key design choices:
- **Provenance is visible.** Elder's name, place, age, consent status all persist in the rail.
- **Reassuring copy.** "Take your time. There is no hurry." Never gamified.
- **One big action.** The record button is the focal point during capture. Everything else steps back.

Files: `index.html`, `FacilitatorApp.jsx`. Shares primitives with Learn mobile (`../learn_mobile/Primitives.jsx`).
